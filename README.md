# IELTS ProAcademy – Modern React Landing Page

![React](https://img.shields.io/badge/React-17.0.2-blue?logo=react&logoColor=white)
![TailwindCSS](https://img.shields.io/badge/Tailwind%20CSS-3.0.24-blue?logo=tailwindcss&logoColor=white)

![License](https://img.shields.io/badge/License-MIT-green)

A **modern, responsive, and animated landing page** for a fictional IELTS Institute built with **React, Tailwind CSS, and Framer Motion**.  

This project demonstrates **frontend development, UI design, responsive layouts, and animations**, perfect for a portfolio showcase.

---

## 🌐 Live Demo

[Click here to view live demo](https://ielts-homepage-five.vercel.app/)  

---

## ✨ Features

- 🎨 **Modern UI** – Clean and professional design with Tailwind CSS  
- 📱 **Responsive Layout** – Works perfectly on desktop, tablet, and mobile  
- 🎬 **Animations** – Smooth scroll-based animations with Framer Motion  
- 🧭 **Navbar with Mobile Menu** – Animated hamburger menu for mobile view  
- 📢 **Hero Section** – Engaging headline, subtext, and call-to-action  
- 📝 **Feature Cards** – Highlights key offerings of the institute  
- 👩‍🎓 **About Section** – Explains why students should choose this institute  
- ⭐ **Testimonials** – Student success stories with star ratings  
- 🚀 **Call-To-Action (CTA)** – Encourages users to book a free trial  
- 📩 **Footer** – Contains links and contact info  

---

## 🛠️ Tech Stack

- **React (Vite)** ⚛️

## ⚡ Installation & Setup

1. Clone the repository:
git clone https://github.com/your-username/ielts-homepage.git
cd ielts-homepage

Install dependencies:

npm install


Start the development server:

npm run dev


Open your browser at http://localhost:5173/ (Vite default)

Build for production:

npm run build

🌍 Deployment

You can deploy this project using:

Netlify → Drag & drop dist folder or connect GitHub repo

Vercel → Connect GitHub repo for automatic deployment
